# 六角棋盘视线（Hex Line of Sight）

离线单页应用：Vue 3 + TypeScript + SVG，在整数平面嵌入的六角棋盘上计算观察点到各格心的视线遮挡。所有几何判定使用 `bigint` 有理数精确完成，**不做屏幕像素取样**，因此界面缩放不会改变可见性结论。

## 几何模型

- 轴坐标 `(q, r)`，格心嵌入为 `(2q + r, 3r)`。
- 顶点相对格心依次为 `(0,2) (1,1) (1,-1) (0,-2) (-1,-1) (-1,1)`。
- 观察点 `P` 到目标格心 `T` 的**开线段** `p(t) = P + (T-P)t, 0 < t < 1` 与阻挡六边形的**严格内部**有正长度相交才算遮挡；只擦过顶点或沿边行进（零长度接触）不算。
- 每个阻挡格表示为 6 个半平面 `a·x + b·y + c < 0`，对开线段做有理数 Liang–Barsky 裁剪；区间为空（含零长度）即未遮挡。
- 选中目标时给出最先遮挡格、交入参数 `t` 与有理交入坐标；并列按 **交入位置 → q → r** 裁决（`compareFirstBlocker`）。
- 画布与列表渲染同一份 `analyzeVisibility` 结果，不存在两套几何。

## 界面

- 半径 2～12 的轴坐标棋盘；点击格子可切换阻挡、选择目标或把观察点设到格心。
- 观察点也可直接输入有理坐标（整数或 `a/b` 分数）。
- 缩放滑杆只改变 SVG 显示尺寸，几何结果不变。
- “擦角示例”载入一组经典场景：视线同时擦过 `(0,1)`、`(1,0)` 的共享角点（不遮挡），并从同一顶点进入 `(1,1)` 内部（遮挡，交入 `t=1/3`，点 `(2,2)`）。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器
npm test           # Vitest：独立有理线段裁剪对拍
npm run build      # 类型检查 + 生产构建（输出 dist/）
```

## Docker Compose

```bash
docker compose up --build
# 打开 http://localhost:8080
```

多阶段构建：`node:22-alpine` 内完成 `npm ci && npm run build`，产物由 `nginx:alpine` 托管，无需任何外部服务。

## 测试

`tests/geometry.test.ts` 用小棋盘和一个**独立的**参考实现（直接对绝对顶点做叉积符号裁剪）对拍生产半平面裁剪，覆盖：

1. 普通遮挡：进入内部，交入位置为有理点；
2. 擦过共享角点：两个障碍在同一距离仅边界接触，目标仍可见；同点进入第三格内部则遮挡；
3. 沿共享边行进不遮挡，越过端点进入下一格内部后给出同一有理交入位置；
4. 缩放不变性：整数平面整体放大 1×、3×、7/2× 后交入参数与可见性完全一致。
